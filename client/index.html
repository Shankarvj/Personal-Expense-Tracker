Milestone Progression & Technical Deliverables

Milestone 01: Project Inception & Node Runtime Environment

  • Technical Focus: Node.js initialization, NPM ecosystem, server-side scripting runtime.
  • Deliverables: Problem statement, project charter, functional/non-functional requirements, technology stack matrix, and GitHub repository baseline.
  • Verification: Node v24.21.0, NPM 11.19.0 verified; root package.json and repository initialized.

Milestone 02: Event Loop Architecture & Modular System Design

  • Technical Focus: Node.js Event Loop phases, synchronous execution vs Microtask Queue vs Macrotask Queue.
  • Deliverables: eventloop.js script executing Call Stack → Microtask (Promises) → Macrotask (Timers); Model-View-Controller (MVC) directory structure.
  • Verification: Observed output logged: 1. Start → 2. End → 3. Promise Callback → 4. Timeout Callback.

Milestone 03: Express REST Routing & Protocol Layer

  • Technical Focus: Express.js framework, HTTP verbs (GET, POST, PUT, DELETE), JSON body parsing, and route handlers.
  • Deliverables: Express server listening on port 5000, /api/expenses and /api/users routes registered.
  • Verification: Clean JSON request/response cycles verified via Postman and interactive REST console.

Milestone 04: Middleware Pipeline & Resilient Error Interceptor

  • Technical Focus: Middleware chaining, request logging, CORS handling, and centralized error interception.
  • Deliverables: loggerMiddleware.js capturing timestamps & routes; errorMiddleware.js catching unexpected exceptions with uniform JSON responses.
  • Verification: All requests logged to stdout; 500 errors gracefully handled without crashing the server process.

Milestone 05: Cloud Database Integration & Data Modeling

  • Technical Focus: MongoDB Atlas cloud database, Mongoose ODM schemas, field constraints, and .env secret management.
  • Deliverables: server/config/db.js connection module, Expense.js and User.js Mongoose schemas.
  • Verification: Handshake to Atlas cluster confirmed: MongoDB Connected: ac-jma4bjr-shard-00-01.bh9uccy.mongodb.net.

Milestone 06: CRUD Engine, Advanced Querying & Filtering

  • Technical Focus: Full CRUD operations, dynamic filtering (category, type, date range, search), and financial summaries.
  • Deliverables: expenseController.js supporting multi-attribute querying, real-time calculations for balance, income, expense, and savings rate.
  • Verification: Full suite of Create, Read, Update, Delete test cases passed (201 Created, 200 OK).

Milestone 07: Cryptographic Authentication, Bcrypt Hashing & JWT Security

  • Technical Focus: User registration, salted password hashing via Bcrypt, stateless JWT issuance, and route protection guards.
  • Deliverables: registerUser and loginUser controllers; 10 salt rounds with Bcrypt; authMiddleware.js validating Bearer tokens.
  • Verification: Passwords stored strictly as 60-character hashes; protected endpoints reject missing or invalid tokens with HTTP 401 Unauthorized.
